# Recebimento Turbo - aplicativo Android (APK)

Instalador do aplicativo **Recebimento Turbo** (Fácil Express / RT3 Transporte) para o celular do operador.

- Versão: 1.0.0 (build 1)
- Arquivo: `RecebimentoTurbo-1.0.0.apk` (~117 MB)
- Gerado pelo Base44

## Como instalar
1. Baixe o arquivo APK na aba **Releases**.
2. Abra o arquivo no celular.
3. Se o Android pedir, permita a instalação de fontes desconhecidas para o navegador usado no download.
4. Abra o app e informe o ID de acesso entregue pela operação.
